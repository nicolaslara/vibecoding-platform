This is a Vite + React app. The dev server is already running on port 8080
with hot reload: do not start, stop or reconfigure it.

- Edit files under src/, starting with src/App.jsx. Styles go in src/App.css.
- `npm install <package>` works if you need a package.
- Do not run a build, add a backend, or touch vite.config.js or package.json scripts.
- The user watches the page reload while you work. Build it in many small edits:
  first a short version that already looks good, then one section or one
  improvement per edit, until the page is rich and polished.
- Once a file exists, never write it again in one go. Edit only the lines that change.
- Every edit must leave the page working.
